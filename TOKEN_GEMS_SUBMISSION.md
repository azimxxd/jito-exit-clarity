## Proposed TokenGems contribution

**JitoSOL — let users explore exit trade-offs before connecting a wallet.**

This review covers JitoSOL's public product page and unstaking documentation. The homepage emphasizes no exit penalties. The documentation already distinguishes instant Jupiter trading from direct unstaking, including a protocol fee and a wait. My suggestion concerns when users encounter this explanation, not hidden fees.

The UX hypothesis is that a new user could read “no exit penalties” as “no exit costs.” A small comparison beside the staking discovery flow could explain the distinction before wallet connection: enter an amount, see both routes, review the assumptions, then understand costs, timing and remaining actions.

I built an independent frontend concept, Jito Exit Clarity, to make the proposal concrete. It has an editable mock JitoSOL-to-SOL rate, hypothetical trading and slippage costs, a modeled 0.1% direct unstaking fee, and a breakdown of each result. It highlights preference fit for speed, cost transparency or simplicity without recommending a financially superior route. The direct journey includes deactivation, waiting and a later withdrawal.

The expected benefit is better comprehension before commitment. That benefit has not been measured. I would compare the existing discovery flow with this concept and ask new users to explain the costs, rate uncertainty, waiting period and next steps.

Question for the team: would a pre-connection comparison complement the existing documentation, and which live quote and protocol data would be needed to make it accurate?

Prepared with AI assistance from public sources. No wallet connection, deposit, swap, unstaking transaction, user interview or usability study was performed. All prototype outputs are fictional scenarios; network and account costs are excluded. Not affiliated with or endorsed by Jito.
